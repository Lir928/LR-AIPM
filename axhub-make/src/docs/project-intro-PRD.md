# AIPM Workflows 项目介绍页需求文档（工作台正本）

本文件为 AIPM Workflows 项目介绍页的"工作台 PRD 正本"，用于指导项目介绍页的实现和维护。此页面旨在专业、清晰地介绍 AIPM Workflows 项目的逻辑、机制和完整流水线体系，帮助新用户快速理解项目并上手使用。

## 1. 业务背景

AIPM Workflows 是一个下一代 AI 驱动的产研自动化底座，致力于解决从需求到原型的传统开发瓶颈。通过 AI 的强大能力，构建了从一句话需求到高保真原型的完整自动化闭环。本文档旨在规范 AIPM Workflows 项目介绍页的功能和设计要求，确保页面能够准确传达项目价值、核心机制和使用方式，提升用户对项目架构和流水线体系的理解。

## 2. 功能需求

### 2.1 项目概览展示

- 展示项目名称、核心定位和价值主张
- 阐述项目核心机制（需求→PRD→Prompt→原型→预览的自动化流程）
- 阐释"All-in-Axhub"架构理念
- 提供清晰的内容导航

### 2.2 流水线体系展示

- 按主线必经/可选流程分组展示10大核心自动化流水线
- 每个流水线显示：编号、名称、触发词、简要说明
- 点击卡片可查看流水线详情弹窗
- 详情弹窗包含流程序号、标题、触发词和详细说明

### 2.3 上手指南

- 展示3大常见使用场景的简明操作步骤
- 场景A：升级现有页面（使用页面还原或需求梳理）
- 场景B：迭代已归档页面
- 场景C：新增页面

### 2.4 技术架构展示

- 展示项目技术栈（React、TypeScript、Axhub Make、Trae IDE等）
- 提供目录结构示意图
- 包含核心技术理念说明

### 2.5 导航与页脚

- 固定顶部导航，包含概览/流水线/上手指南/架构等链接
- 页脚包含项目信息和文档链接

## 3. 用户角色

本页面为公开页面，面向所有希望了解 AIPM Workflows 项目的开发者、产品经理和设计师，无需特殊权限。

## 6. 交互设计

- 滚动时导航栏半透明毛玻璃效果
- 平滑滚动到页面指定区域
- 导航链接高亮显示当前区域

### 6.2 流水线卡片交互
- 卡片悬停上浮效果
- 点击卡片弹出详情模态框
- 模态框内显示完整流水线说明

### 6.3 响应式适配
- 桌面端：三列布局展示流水线和上手指南
- 平板端：双列布局
- 移动端：单列布局

## 8. 技术实现

### 8.1 技术栈

- React 18.x
- TypeScript 5.x
- Lucide React (图标库)
- CSS Modules/样式文件

### 8.2 组件结构

- `ProjectIntro`: 主组件，包含所有页面区块
- `mainWorkflows`: 主线流水线数据
- `optionalWorkflows`: 可选流水线数据
- `techStack`: 技术栈数据
- `directoryStructure`: 目录结构文本

### 8.3 状态管理

- `scrollY`: 滚动位置状态，用于导航栏样式变化
- `isLoaded`: 页面加载状态，用于初始动画
- `showWorkflowModal`: 流水线弹窗显示状态
- `selectedWorkflow`: 选中的流水线ID
