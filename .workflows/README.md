# 工作流总览

本项目包含以下工作流（流水线），用于不同场景的原型开发：

## 00 - 统一页面开发流水线（入口）
- **触发词**：`/开发页面`、`/页面开发`、`开始开发`、`我要做页面`
- **作用**：智能路由到最适合的工作流，是所有原型工作的统一入口
- **AI职责**：分析用户需求，决定启动哪个具体流水线

## 01 - 现有资产盘点流水线
- **触发词**：`执行资产盘点`
- **作用**：扫描整个代码仓库，生成项目资产清单（原型、组件、主题、数据库表）
- **AI职责**：分析扫描结果，识别可复用资产

## 02 - 需求转PRD流水线
- **触发词**：`执行需求梳理`
- **作用**：将原始业务需求结构化为标准 PRD，并生成用于 Axhub Make 的 Prompt
- **AI职责**：根据用户需求编写 PRD，包括功能列表、用户画像、业务流程

## 03 - 需求文档双向同步机制
- **触发词**：`执行Prompt同步`
- **作用**：PRD 修改后自动同步到 Prompt
- **AI职责**：保持 PRD 和 Prompt 的一致性

## 04 - 原型生成与基础增强流水线
- **触发词**：`执行原型生成`
- **作用**：根据 PRD + Prompt 生成实际原型代码
- **AI职责**：编写 React 组件、集成数据、实现交互

## 05 - 交付前代码审查与收口
- **触发词**：`执行代码审查`
- **作用**：形式化审查，确保代码质量
- **AI职责**：生成审查报告，帮助发现潜在问题

## 07 - 项目启动与预览流水线
- **触发词**：`启动项目预览`
- **作用**：启动 Axhub Make 预览环境，实时查看原型效果
- **AI职责**：确保预览环境正常运行

## 08 - 原型深度补强流水线（可选）
- **触发词**：`执行原型增强`
- **作用**：为原型添加复杂交互、状态机等高级功能
- **AI职责**：添加复杂逻辑和高级交互

## 09 - 原型归档与升级流水线
- **触发词**：`执行归档` 或 `执行恢复`
- **作用**：归档完成的原型或从归档恢复继续开发
- **AI职责**：确保归档和恢复的完整性

## 10 - 老项目页面还原流水线
- **触发词**：`执行页面还原`
- **作用**：将 Chrome 扩展导出的老系统页面数据包，忠实还原为 Axhub Make 原型页面
- **AI职责**：精确还原原页面视觉与布局，不主动改版，不擅自简化

> **重要**：所有数字编号的流水线文件都有明确的执行顺序和依赖关系，不得随意修改。
