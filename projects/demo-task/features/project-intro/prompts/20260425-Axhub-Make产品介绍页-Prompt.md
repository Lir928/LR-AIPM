# 20260425 - Axhub Make 产品介绍页（Prompt 归档）

## 系统概述
创建一个现代化的产品介绍页面，展示 Axhub Make AI 驱动原型设计工具的核心价值和功能特性。

## 页面设计

### 1. 导航栏
- 品牌 Logo 和名称（Axhub Make）
- 导航链接：首页、功能、流水线、技术、团队
- 开始使用按钮
- 滚动时导航栏样式变化

### 2. 英雄区域
- AI 驱动原型设计工具标签
- 主标题：让原型设计更简单、更智能
- 副标题描述
- 立即体验和查看文档按钮
- 用户数据统计（50+设计组件、10k+用户信赖、99%满意度）

### 3. 关于产品区域
- 页面标题：重新定义原型设计体验
- 产品介绍文字
- 特性亮点卡片（效率提升10x、无缝协作）

### 4. 核心能力区域
- 6个功能特性卡片：智能原型生成、语义化文档、多主题支持、快速迭代、数据管理、安全可控

### 5. 流水线介绍区域
- 9个流水线卡片，点击可查看详情弹窗

### 6. 技术栈区域
- 6个技术卡片（React、TypeScript、Vite、Ant Design、Tailwind、ECharts）

### 7. 团队介绍区域
- 4位团队成员卡片

### 8. 页脚区域
- 品牌信息、快速链接、资源链接、联系方式

## 交互设计
- 滚动时导航栏样式变化
- 特性卡片动画延迟效果
- 流水线卡片点击打开详情弹窗
- 平滑滚动导航

## 视觉设计
- 现代科技风格、深色背景、渐变色和发光效果
- 卡片式布局、动画效果增强用户体验

## 技术要求
- React + TypeScript + Tailwind CSS
- Lucide React 图标库
- 响应式设计
- 滚动监听和动画效果
