# 老项目页面还原 - 快速上手指南

## 🎯 什么是页面还原？

页面还原是将**旧系统页面**精确转换为**Axhub Make原型**的过程，目标是1:1像素级还原原页面的视觉与布局。

与新建页面不同，还原的目标是**忠实复刻**，不是创新设计。

## 📋 准备工作

### 1. 准备导出包
从旧系统获取完整的导出包，应包含以下文件：

```
导出包/
├── manifest.json        # 页面元数据
├── screenshot.png       # 页面截图（最重要！）
├── theme.json          # 设计令牌（颜色、字体、间距等）
├── content.md          # 文本内容
├── sections/           # 页面分段信息
├── structure/          # DOM结构数据
├── flat/               # 平面化数据
└── topology/           # 元素拓扑关系
```

### 2. 放置导出包
将导出包放到临时工作目录：

```bash
mkdir -p workbench/_incoming/$(date +%Y-%m-%d)/<页面名>/
cp -r <你的导出包>/* workbench/_incoming/$(date +%Y-%m-%d)/<页面名>/
```

例如：
```bash
mkdir -p workbench/_incoming/2026-04-25/任务详情页/
# 将你的导出包内容复制到这里
```

## 🚀 开始还原

### 1. 启动还原流水线
在AI对话框中输入：
```
执行页面还原
```
或
```
还原老页面
```

### 2. AI自动化流程
AI将自动执行以下步骤：

1. **数据注入**：读取导出包所有信息，优先级为：
   - ⭐⭐⭐⭐⭐ `screenshot.png` - 视觉真相
   - ⭐⭐⭐⭐ `theme.json` - 精确设计令牌  
   - ⭐⭐⭐ `sections/` - 页面分段结构
   - ⭐⭐ `content.md` - 文本内容

2. **主题提取**：从 `theme.json` 生成精确的设计主题

3. **分段还原**：按 `header → sidebar → main-content → footer` 顺序逐段还原

4. **视觉校验**：对比还原结果与原截图的相似度

## 📊 质量标准

- **视觉相似度**：≥ 85% 
- **颜色精确性**：使用 `theme.json` 中的确切RGB值
- **字体精确性**：使用 `theme.json` 中的确切字体族
- **间距精确性**：使用 `theme.json` 中的确切间距值
- **交互完整性**：原页面所有交互元素均需还原

## 🔍 验证还原结果

### 自动验证
脚本会自动生成视觉差异报告：

```bash
# 比较原始截图与生成原型
node axhub-make/scripts/visual-diff.mjs <导出包路径> <原型URL>
```

### 手动验证
访问生成的原型页面，检查：
- [ ] 颜色与原图一致
- [ ] 字体与原图一致  
- [ ] 间距与原图一致
- [ ] 布局结构一致
- [ ] 交互元素完整

## 🛠️ 常见问题

### Q: 还原精度不够高怎么办？
A: 检查导出包是否包含完整的 `theme.json` 和 `sections/` 目录

### Q: 颜色不匹配如何解决？  
A: 确保 `theme.json` 中的颜色值被正确提取，AI会优先使用截图验证

### Q: 某些交互元素丢失？
A: 检查 `flat/nodes/` 目录中的节点信息是否完整

## 🎨 生成的文件

还原完成后，你会看到：

```
axhub-make/src/
├── themes/<页面名>-restored/     # 精确提取的主题
│   ├── designToken.json         # 设计令牌
│   ├── style.css               # 样式文件
│   └── index.tsx               # 主题组件
└── prototypes/<页面ID>/         # 生成的原型
    ├── index.tsx               # 主组件
    ├── style.css               # 样式
    ├── components/             # 组件目录
    └── spec.md                 # 规格文档
```

## 📝 还原与创建的区别

| 特点 | 页面还原 | 页面创建 |
|------|---------|---------|
| 目标 | 1:1复刻原页面 | 创造新页面 |
| 设计 | 忠实原貌 | 自由发挥 |
| 颜色 | 使用原值 | 使用主题 |
| 布局 | 保持不变 | 重新设计 |
| 交互 | 全部还原 | 按需添加 |
