# 项目启动与预览流水线

## 触发词

`启动[项目名称]`（如：启动基层组织工作台、启动demo-task）

## 流水线概述

本流水线用于启动 Axhub Make 预览环境，供 `02/04/08` 阶段边看边改。

它是**辅助动作**，不是业务主线的一部分；通常在 PRD 已明确、准备生成或修改原型时执行。

## AI 协同顺序与执行逻辑

当接收到触发词后，AI 助手必须主动调用内置终端 (Terminal)，按严格顺序执行以下两条命令：

1. `npm run switch [解析出的项目名称]`
2. `npm run dev:axhub-make`

推荐执行时机：

- 在完成 `02` 后，准备查看或生成原型时
- 在执行 `04` 前后
- 在执行 `08` 时，需要实时验证交互效果

## 后续动作

在聊天框向用户反馈：
- "✅ [项目名称] 环境已激活，Axhub Make 引擎已启动。"
- "🔗 预览地址以终端输出的 Local URL 为准（端口可能自动变化）。"
- "📌 如果要稳定读取当前端口：读取 `axhub-make/.axhub/make/.dev-server-info.json`，使用其中的 `port` 组合得到 `http://localhost:{port}/`。"

## 执行条件

- 目标项目目录已存在于 `projects/` 目录下
- 网络连接正常
- Axhub Make 本地引擎已安装

## 预期成果

- 目标项目环境已激活
- Axhub Make 引擎已启动
- 浏览器已自动打开并显示项目预览
- 用户可以继续进入 `04` 生成原型，或直接修改 `axhub-make/src/prototypes/`

## 注意事项

- 确保目标项目名称正确，且已存在于 `projects/` 目录下
- 如遇启动失败，检查项目目录结构是否完整
- 如需停止 Axhub Make 引擎，可在终端中按 Ctrl+C 终止进程
