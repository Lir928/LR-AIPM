# Axhub Make 产品介绍页需求文档

本文件为“文档 Tab 正本”，用于统一维护产品介绍页需求，避免与 `projects/` 下的归档文件出现重复与分叉。

## 1. 业务背景

Axhub Make 是一款新一代 AI 辅助原型工具，通过深度集成 AI 能力，将原型设计从繁琐的手动操作中解放出来，让团队能够更专注于创意和用户体验本身。本文档旨在规范 Axhub Make 产品介绍页的功能和设计要求，确保页面能够准确传达产品价值主张，提升用户对产品的认知和理解。

## 2. 功能需求

### 2.1 首页展示

- 展示产品名称、品牌标识和核心价值主张
- 显示用户数据统计（设计组件数、用户信赖数、满意度）
- 提供立即体验和查看文档两个主要行动按钮
- 支持滚动渐变背景效果和导航栏随滚动变色

### 2.2 功能特性展示

- 展示6大核心功能特性卡片
- 每个卡片包含图标、标题和描述文字
- 卡片支持动画延迟效果

### 2.3 流水线介绍

- 展示9大自动化流水线
- 每个流水线卡片显示编号、标题和简介
- 点击卡片可查看流水线详情弹窗
- 详情弹窗包含流程序号、标题和详细说明

### 2.4 技术栈展示

- 展示 React、TypeScript、Vite、Ant Design、Tailwind、ECharts 等技术
- 每个技术卡片显示名称和版本号
- 支持自定义主题色

### 2.5 团队介绍

- 展示4位核心团队成员
- 每个成员卡片包含姓名、职位和头像

### 2.6 页脚信息

- 包含品牌信息、快速链接、资源链接和联系方式
- 提供社交媒体链接入口

## 3. 用户角色

本页面为公开页面，所有访问者均可查看，无需特殊权限。

## 6. 技术实现

### 6.1 技术栈

- React 18.2.0
- TypeScript 5.9.3
- Vite 5.0.0
- Lucide React (图标库)
- Tailwind CSS (样式)

### 6.2 组件结构

- `ProjectIntro`: 主组件，包含所有页面区块
- `features`: 功能特性数据
- `workflows`: 流水线数据
- `techStack`: 技术栈数据
- `teamMembers`: 团队成员数据

### 6.3 状态管理

- `scrollY`: 滚动位置状态
- `isLoaded`: 页面加载状态
- `showWorkflowModal`: 流水线弹窗显示状态
- `selectedWorkflow`: 选中的流水线ID

## 7. 原型与归档

- 原型入口：`src/prototypes/project-intro/`
- 归档位置：`projects/<project>/features/<pageId>/` 为单一正本（PRD/Prompt/交付物）；`projects/<project>/docs/` 仅放索引/引用（可选）
