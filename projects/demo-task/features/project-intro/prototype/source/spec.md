# AIPM Workflows 项目介绍页规格文档

## 1. 页面概述

本页面为 AIPM Workflows 项目的自我介绍原型页面，认真向访客说明项目的逻辑、机制和完整流水线体系，帮助新用户快速理解项目并上手使用。

## 2. 设计风格

### 2.1 美学方向
- **风格定位**：清晰、专业、实用导向（不是营销页，而是项目说明页）
- **色调**：以靛蓝色为主色，琥珀色为强调色
- **排版**：信息层次分明，段落间距舒适
- **空间**：适度留白，但以内容密度为优先

### 2.2 颜色方案
- 主色调：#6366F1（Indigo）
- 强调色：#F59E0B（Amber）
- 背景：浅灰白到浅紫渐变
- 文字：深灰到浅灰层级

### 2.3 视觉效果
- 毛玻璃导航栏
- 渐变背景和光晕
- 卡片悬停上浮效果
- 流水线弹窗交互
- 平滑滚动导航

## 3. 页面结构

### 3.1 导航栏
- 固定顶部，滚动变色
- 包含：Logo、导航链接（概览、流水线、上手指南、技术架构）

### 3.2 英雄区域
- 项目名称 + 一句话定位
- 核心价值说明段落（简单直接，一看就懂）
- 两个按钮：查看上手指南 / 查看流水线

### 3.3 项目概览
- 项目是什么、解决什么问题
- 核心机制：AI驱动 → PRD → Prompt → Axhub Make → 原型
- 架构说明：All-in-Axhub

### 3.4 流水线体系
- 按主线必经/可选流程分组展示
- 每条流水线显示：编号、名称、触发词、简要说明
- 点击可查看弹窗详情

### 3.5 上手指南
- 三种场景的最简操作步骤
- 场景A：升级旧页面
- 场景B：继续迭代已归档页面
- 场景C：新增页面

### 3.6 技术架构与目录结构
- 技术栈卡片
- 目录结构示意图
- 依赖安装说明

### 3.7 页脚
- 项目链接、License 信息

## 4. 交互设计

- 滚动时导航栏样式变化
- 流水线卡片点击打开详情弹窗
- 平滑滚动导航
- 卡片悬停上浮效果

## 5. 响应式断点

- 桌面端：> 1024px
- 平板端：768px - 1024px
- 移动端：< 768px

## 6. 技术实现

- React + TypeScript
- Lucide React 图标库
- Tailwind-style CSS（BEM 命名）
- 响应式设计
