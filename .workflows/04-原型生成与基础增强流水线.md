# 原型生成与基础增强流水线

## 触发词
`执行原型生成`

## 流水线概述
本流水线用于读取 Prompt，并在 `axhub-make/src/prototypes/[pageId]/` 下生成或重建可交互原型页面。

这是主线中的“原型落地”步骤，并且默认应做到“可演示”，而不是只生成静态壳子。

默认包含：

- 页面结构与视觉样式
- 基础交互反馈
- 常见状态切换
- 弹窗、筛选、Tab、表单等演示逻辑
- 必要的假数据驱动展示

但不是任何时候都必须执行：

- **原型不存在**：应优先执行
- **原型已存在且只是继续改**：可直接修改现有原型，不必强制重跑

## AI 协同顺序与执行逻辑

### 步骤 1：解析 Prompt
- **任务**：读取 `projects/[项目名称]/features/[页面英文ID]/prompts/YYYYMMDD-[功能名称]-Prompt.md` 文件，解析其中的设计规范和页面结构。
- **输出**：解析后的 Prompt 配置和技术栈信息。

### 步骤 2：直接构建原型
- **任务**：在 `axhub-make/src/prototypes/[页面英文ID]/` 目录下，直接生成 `index.tsx` 和相关样式文件，并同时补齐基础演示交互。
- **输出**：生成的原型页面文件。

### 步骤 3：输出预览地址
- **任务**：在聊天框提示用户原型生成完毕，并提供实时预览地址。
- **输出**：
  - "✅ 原型生成完毕！"
  - "🔗 预览地址以当前 Axhub Make 启动时终端输出的 Local URL 为准（端口可能自动变化），路径为 /prototypes/[页面英文ID]"

## 执行条件
- 目标项目目录已存在于 `projects/` 目录下
- `projects/[项目名称]/features/[页面英文ID]/prompts/` 目录下存在对应的 Prompt 文件
- Axhub Make 本地引擎已安装并运行

## 预期成果
- 在 `axhub-make/src/prototypes/` 目录下生成可交互的高保真原型页面
- 原型页面可在 Axhub Make 的 Local URL 下，通过 `/prototypes/[页面英文ID]` 实时预览
- 原型页面至少包含基础交互能力与响应式适配
- 后续通常直接手工迭代；只有复杂返修时才进入 `08`

## 注意事项
- 确保 Prompt 文件包含详细的设计规范和页面结构
- 确保 Axhub Make 引擎已启动并正常运行
- 生成的原型页面仅用于预览和演示，不用于生产环境
- 如果目标目录下已有可用原型，应先判断是“覆盖重建”还是“基于现有代码继续修改”
- 如果首轮生成仍明显不足，再把 `08` 作为补充动作，而不是默认下一步
