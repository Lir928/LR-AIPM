# 原型归档与升级流水线（精简版）

目标：减少工作台负担，保证"原型 + PRD"在工作台阶段一致；归档后把正本同步到项目 features，并移除工作台原型，避免分叉。

这是主线中的**最后一步**。页面阶段性完成后执行；后续要继续改时，再先恢复回工作台。

## 核心原则

- 工作台阶段
  - 原型：`axhub-make/src/prototypes/<pageId>/`
  - PRD：`axhub-make/src/docs/<pageId>-PRD.md`
- 归档阶段（正本）
  - `projects/<projectName>/features/<pageId>/`
    - `prd/PRD.md`
    - `iterations/`（每次迭代材料）
    - `prompts/`（按日期沉淀 Prompt）
    - `prototype/source/`（原型源代码快照）
    - `prototype/export/zip|html/`（HTML 导出交付物：zip + 解压）

## 归档（完成后移除工作台原型）

前置条件：

- 在线模式：Axhub Make 已启动（用于导出 HTML），当前端口从 `axhub-make/.axhub/make/.dev-server-info.json` 读取
- 离线模式：无需启动 Axhub Make，使用 `--offline` 参数跳过 HTML 导出

执行：

- 在线归档：`npm run archive:prototype -- <projectName> <pageId>`
- 离线归档：`npm run archive:prototype -- <projectName> <pageId> --offline`

结果：

- 归档区产物生成完毕
- `axhub-make/src/prototypes/<pageId>` 被移除（除非使用 `--keep-source`）
- PRD 采用**双向引用**机制：归档时复制 PRD 到归档区，工作台 PRD 保留不变，保持两份同步
- 如需保留工作台原型进行并行观察，可临时使用 `--keep-source`
- 如当前尚无工作台 PRD，可临时使用 `--no-prd`
- 操作日志自动记录到 `projects/<projectName>/features/<pageId>/changelog.md`

## 恢复（归档页面需要继续迭代）

执行：

- `npm run restore:prototype -- <projectName> <pageId>`
- 如工作台已有同名原型，使用 `--force` 覆盖

结果：

- 还原原型到 `axhub-make/src/prototypes/<pageId>/`
- 如工作台 PRD 不存在，从归档区复制到 `axhub-make/src/docs/<pageId>-PRD.md`
- 如工作台 PRD 已存在（双向引用），则跳过复制，两份保持同步
- 操作日志自动记录

## 升级已归档页面（建议闭环）

1. 先恢复：`npm run restore:prototype -- <projectName> <pageId>`
2. 在工作台迭代（可配合 `03/04`，复杂情况再配合 `08`）
3. 完成后再归档：`npm run archive:prototype -- <projectName> <pageId>`

## 在主线中的位置

- 新增页面：通常在 `02 -> 07 -> 04 -> 03` 之后执行；复杂返修时再插入 `08`
- 升级外部页面：通常在 `workbench/_incoming -> 02 -> 07 -> 改原型/04 -> 03` 之后执行；复杂返修时再插入 `08`
- 升级已归档页面：通常在"恢复 -> 修改 -> 再归档"的闭环中执行
